Where the dead units actually live — kwta_channel, 600 labels

The aggregate 43.5% looked like network-wide capacity collapse. It is almost entirely the fully connected layer, which holds 128 of the 176 counted units. The convolutional layers — the ones the axis change touches — were never in trouble. (kwta_global is similar: 0.0% / 5.6% / 63.0%.) This matters: since a 2-D input makes both axes identical, the axis change cannot have fixed the FC layer, so dead units were not what was holding the mechanism back.

Table view — both budgets, all arms
What this changes. The mechanism that pays is real lateral inhibition among feature detectors sharing a receptive field — not sparsity as such, and not recovered capacity. Total sparsity was held identical between the two axes, so nothing here is explained by one arm simply keeping more units. And the effect is confined to the smallest budget (+1.43 at 600 labels, +0.19 and not significant at 3,000), which is how a prior is supposed to behave: it earns its place only where there is too little data to learn the structure. The next run tests exactly that — sweeping k down to 10 shots per class. If the interpretation is right the advantage must grow as labels get scarcer; if it peaks at 600 it was a local effect and should not be generalized.
