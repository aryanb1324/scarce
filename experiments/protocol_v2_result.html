Pattern separation: the mechanism works, exactly where it was predicted to

Separation = mean pairwise Jaccard overlap of active-unit sets for same-class pairs minus different-class pairs. Higher is better. kWTA's advantage is 2.24× at 600 labels and decays monotonically to nothing by 30,000 — the hypothesis's own mechanistic prediction. Note the dense baseline climbing to meet it: given enough data it discovers the separated sparse code that kWTA imposes.

The two diagnostics disagree, and that is the finding. kWTA buys genuinely better-separated codes and pays for them with roughly half its capacity, so the effects cancel and accuracy lands on "no difference." The dense baseline drifts toward sparse codes on its own as data grows — 77 → 46 active units of 128 — which says sparsity is a useful prior for the low-data regime, and a prior is only worth holding if it doesn't cost half the network.
